MIRASH Seven-Output Research Calculator v3.0.0

A frozen routine-laboratory MIRASH core score with seven prespecified outcome-specific mapping heads. The calculator uses the original CHARLS 2011-frozen equations by default.

Default model governance. All seven outputs use the original CHARLS 2011-frozen outcome-specific heads. CHARLS 2015 recalibration results are secondary model-updating sensitivities and are intentionally not used as default equations.
Research-use notice. This tool is not a diagnostic device and does not replace direct assessment of muscle strength, muscle mass, physical performance, or clinician judgment. No diagnostic or treatment cutoff is proposed by this calculator.

Quality-control / applicability notes

The calculator flags values outside the frozen development-domain 8-IQR applicability boundaries. These are not clinical reference ranges and are not formula scaling constants. Positive values are required for all log-transformed inputs.

All calculations are performed locally in the browser; this static page does not transmit or store entered values. Version 3.0.0. Default equations are the original CHARLS 2011-frozen heads; no diagnostic or treatment cutoff is optimized or recommended. Internal self-test pending.
